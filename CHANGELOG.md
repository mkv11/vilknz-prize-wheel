# Изменения

## 1.1.0 — 2026-11-11

- Закрытые каналы Telegram через своего бота: кнопка ⚙ рядом с вкладками, инструкция и поле для токена.
- Основная кнопка сбора теперь «Добавить»; вторая — «Очистить и добавить».
- Повторное «Добавить» с той же ссылки засчитывает только новые комментарии (раньше счётчики сообщений росли).
- Исправления по ревью:
  - ключевая фраза из символов или эмодзи (`+`, `🎁`) больше не отключает фильтр; поддержаны буквы любых алфавитов;
  - сбор и вращение больше не мешают друг другу (раньше «Очистить и добавить» во время вращения вешало страницу);
  - комментарии бота не теряются при обрыве связи; переполнение хранилища браузера показывается явно;
  - анонимные администраторы и удалённые аккаунты не попадают в участники;
  - пробел/Enter при открытом окне победителя закрывают его, а не запускают новую крутку;
  - сбор с t.me повторяет запрос при сетевой ошибке, не теряет уже собранное и предупреждает о неполном сборе;
    несуществующий пост — понятная ошибка;
  - локальный сервер отвечает только своей странице (защита от запросов с чужих сайтов);
  - таймер: мигание кнопки снимается после «+1 мин», клик по цифрам без правки не откатывает время, `2,5` — 2½ минуты;
  - список участников не прыгает наверх при потоке сообщений из чата;
  - Twitch: несуществующий канал — понятная ошибка, популярные чат-боты не считаются участниками.

## 1.0.1 — 2026-11-11

- Таймер «До крутки» (по умолчанию 10 минут): запуск/пауза, ±1 минута, ввод своего времени кликом по цифрам, сброс.
  Когда время выходит, кнопка «Крутить барабан!» мигает; крутку запускает пользователь.
- В окне программы теперь крупно написано, что его нельзя закрывать, пока идёт розыгрыш, и когда закрывать можно.
  То же — в заголовке окна.
- Если порт 8765 занят другой программой, Крутка занимает следующий свободный, а не открывает чужую страницу.
- Исправлено: на Windows вторая копия программы запускалась на том же порту вместо того, чтобы открыть первую.

## 1.0.0 — 2026-11-11

Первый выпуск.

- Сбор уникальных комментаторов поста публичного Telegram-канала, в том числе с нескольких постов.
- Прослушивание чатов идущих трансляций Twitch и YouTube.
- Ключевая фраза без учёта регистра и раскладки (`itr` = `ИТР`).
- Колесо с аватарками, честный выбор победителя через `crypto.getRandomValues`.
- Правка списка участников, музыка с YouTube, настраиваемая длительность вращения.
- Портативный exe для Windows.
